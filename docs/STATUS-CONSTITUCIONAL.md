# Estado Constitucional do Projeto SU Loto

**Data:** 05/08/2026  
**Carteira vigente:** SU Loto - C2  
**Situação:** pendências técnicas e documentais encerradas para elaboração da Constituição v1.0

## Decisões consolidadas

- A planilha oficial define os 300 jogos canônicos.
- O ID oficial sequencial 001-300 é o identificador canônico.
- Os jogos 001-100 formam a Base preservada.
- Os jogos 101-300 formam o Sistema Universal consolidado.
- O aplicativo é derivado e foi auditado em 300/300 jogos.
- Os níveis oficiais são prefixos aninhados da ordem canônica: 001-050, 001-100, 001-150, 001-200 e 001-300.
- O histórico operacional do aplicativo é mantido por uma única rotina automatizada; JSON e CSV são derivados da mesma execução.
- A versão estável documentada é v11 e a beta mais recente documentada é v22.
- O Notion não integra a fonte oficial, não é necessário para reconstrução e não exige exportação constitucional.
